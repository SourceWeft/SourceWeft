# SourceWeft v0.2.0-rc.1

SourceWeft 0.2.0 的第一个发布候选版，面向 Web 与 Docker 自托管试用。本次发布不包含桌面或移动端安装包。

## 本版重点

- 一个镜像适配不同部署地址：Web/API 地址在运行时配置，修改域名或端口无需重新构建。
- Web、鉴权、聊天流和文件访问使用同一入口；服务端请求通过容器内网访问 API。
- 默认包含 PostgreSQL、Redis 和私有 S3 存储，初始化命令生成独立的数据库、存储与应用密钥。
- 上传、文件预览及下载使用认证保护；不同 Compose 项目的数据卷相互隔离。
- 修复首次启动的数据库健康检查、工作区未就绪时的上传操作，以及生产镜像中的内置工具加载。
- 未配置可选网页检索服务时，普通模型聊天仍可使用；显式网页工具调用会明确报告缺少配置。

## 安装

下载本 Release 的 `sourceweft-selfhost-v0.2.0-rc.1.tar.gz` 并解压，在包含 `docker/` 的目录中执行。需要 Docker、Compose v2.24+ 和 POSIX 终端。

```sh
VERSION=v0.2.0-rc.1
IMAGE=ghcr.io/sourceweft/sourceweft:$VERSION
docker run --rm --user "$(id -u):$(id -g)" --entrypoint node \
  -e SOURCEWEFT_IMAGE="$IMAGE" -v "$PWD/docker:/config" "$IMAGE" \
  /app/docker/init-config.mjs /config
docker compose --env-file docker/.env -f docker/docker-compose.yml up -d --wait --wait-timeout 300
```

打开 <http://localhost:3000> 注册登录。聊天与向量索引需要配置模型 Provider 或授权的 BYOK 模型；网页搜索/抓取使用可选的 `ANYCRAWL_API_KEY`。

详细配置、外部存储、端口修改及升级步骤见压缩包中的 `docker/README.md`。

## 镜像与版本

- 镜像：`ghcr.io/sourceweft/sourceweft:v0.2.0-rc.1`。
- 目标架构：`linux/amd64`、`linux/arm64`。
- RC 标记为预发布，不更新 `latest` 或 `0.2` 镜像别名。安装本候选版请使用完整版本标签。

## 升级注意事项

- 保留现有 `.env`，不要在已有安装上重新运行初始化命令。
- 升级前备份数据库、文件存储和加密密钥；使用与镜像版本对应的 Compose 文件。
- 使用旧版固定卷的实例，按 `docker/README.md` 添加 `compose.legacy-volumes.yml`，避免误建空数据卷。
- `docker compose down` 保留数据；`down -v` 会删除数据。
- 数据库迁移后回退需要恢复兼容备份，仅降级镜像不等于回滚数据。

## 验证与已知限制

- 发布质量门禁覆盖 Node 22/24 测试、类型与代码检查、Docker 安装、私有文件访问、流式聊天、主动停止和换地址重启后的数据保留。
- 安装验收使用明确配置的测试模型服务，未验证所有外部模型供应商的兼容性或响应质量。
- 本地实测首条回复曾在约 4–8 秒间波动，停止后的状态同步也曾超过 5 秒；本候选版不承诺稳定的低延迟。
- macOS/Windows 安装包及移动端不属于本次发布范围。
