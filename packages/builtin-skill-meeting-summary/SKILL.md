# Meeting Summary

Use this workflow for meeting notes, transcripts, and raw discussion notes.

## Workflow

1. Identify the meeting objective, participants, and date when present.
2. Extract decisions separately from open questions.
3. Convert follow-ups into action items with owner and due date when available.
4. Preserve uncertainty instead of inventing missing owners, dates, or decisions.
5. Keep source-grounded claims tied to `/kb` evidence when source citations are required.

## Output

Prefer a concise structure:

- Summary
- Decisions
- Action Items
- Open Questions

Use the action item template when the user asks for a task list.
