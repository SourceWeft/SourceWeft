# Page design

Choose typography, spacing and a visual direction that fit the audience. Use semantic headings, readable line lengths, clearly differentiated sections and meaningful data labels. Reports should remain useful when printed or read linearly; landing pages should make the value and next action clear.

Use fluid grids and deliberate breakpoints. Preserve content and functionality on narrow screens. Intentional local horizontal scrolling for a wide table is acceptable; accidental whole-page overflow is not. Keep controls keyboard-accessible and label them explicitly.

The provisioned font catalog includes the upstream presentation web fonts and CJK/symbol coverage, but page layouts do not inherit presentation templates. Declare the desired embedded families consistently in CSS, SVG and Canvas. Custom fonts must be explicitly provided and validated.
