01 / Findings

先建立清楚的关系，再增加信息。

从问题出发

把使用场景和决策目标放在报告开头，让读者知道接下来的材料为何值得关注。

每个结论都对应证据和明确的限制。图表、说明与行动建议使用相同术语。

让过程可复查

保留材料的版本和来源，使后续修订能够确认依据，而不是覆盖过去的记录。

读者可以按顺序阅读，也可以通过页内链接直接进入最相关的部分。
