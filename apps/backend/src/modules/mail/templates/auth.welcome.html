Three ways to hand off work

  1. Ask in a chat
    State the goal. The agent plans the work, runs sub-agents in parallel, and returns a report, slides, or a table.
    Start a chat
  2. Schedule it
    Save a prompt to run on a schedule. Each run puts its result in a new chat.
    Create a scheduled task
  3. Hand it to the workspace assistant
    Once enabled, ask for work in the shared feed. The assistant opens a ticket for each request, works on them in parallel, and reports back.
    Open the assistant

You stay in control

  • Traceable. Answers cite their sources, and the assistant shows the reason for every decision.
  • Asks when unsure. When information is missing, the agent asks you instead of guessing.
  • Approval before changes. Risky actions need your approval. Unattended runs are read-only.

Use it anywhere

One account and workspace on the web, in your phone's browser, and in the desktop app for macOS, Windows, and Linux. The desktop app can also run tasks on your computer and work in local folders. iOS and Android apps are coming soon.

Download the desktop app
