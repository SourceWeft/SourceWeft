# Meeting Summary

Use this skill when a conversation needs to turn raw meeting notes, transcripts,
or agenda fragments into a concise summary with decisions and action items.

## What It Does

- Extracts key topics and decisions from meeting material.
- Separates action items from general discussion.
- Keeps owner, due date, and follow-up fields explicit when available.
- Uses the included action-items template for consistent output.

## When To Install

Install this skill for workspaces that regularly summarize calls, planning
sessions, research syncs, or customer meetings.

## Notes

This is a builtin SourceWeft skill stored in the backend repository. Its
instructions are reviewed with code changes and are exposed to agents only when
the workspace installs it and the user selects it for a turn.
