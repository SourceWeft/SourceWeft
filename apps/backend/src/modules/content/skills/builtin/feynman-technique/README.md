# Feynman Technique

Use this skill when a learner wants to understand a concept by teaching it in
plain language, finding the weak spots, and rebuilding the explanation.

## What It Does

- Turns a topic into a short coaching loop.
- Asks one focused question at a time.
- Identifies jargon, unclear causal links, and gaps in the learner's explanation.
- Helps rewrite the explanation in simpler language with a concrete example.
- Ends with short self-check questions to confirm understanding.

## When To Install

Install this skill for workspaces that support learning, research review,
technical onboarding, studying, or concept explanation workflows.

## Notes

This is an official SourceWeft skill. It is exposed to agents only after the
workspace installs it and the user selects it for a turn.
